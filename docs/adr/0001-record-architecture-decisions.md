# ADR 0001: Registro de decisiones de arquitectura

**Status**: Accepted

## Contexto

A medida que el proyecto Store Lite crece, las decisiones técnicas se vuelven más complejas. Sin un registro, es fácil olvidar por qué elegimos una herramienta sobre otra, lo que dificulta el onboarding de nuevos desarrolladores y la evolución del sistema.

## Decisión

Adoptamos el uso de Architecture Decision Records (ADRs) para documentar cada cambio significativo en la arquitectura, patrones de diseño o stack tecnológico.

## Consecuencias

- **Positivas**: Mayor transparencia, documentación viva de la tecnología, facilidad para debatir cambios futuros.
- **Negativas**: Leve sobrecarga al tener que escribir un documento por cada decisión mayor.
